# Контекст Telegram-сообщений

Бот может создать напоминание с bounded-контекстом исходного Telegram-сообщения:
пересланного сообщения или поста канала, сообщения в reply, ссылки, фото и документа.
Обычный текстовый reminder без ссылки, media или forward/reply остаётся прежним и не
создаёт context row.

## UX

- Ответь на сообщение командой `напомни об этом завтра в 09:00`.
- Для явной ссылки, фото, документа или пересланного сообщения можно отправить контекст
  без расписания; бот сохранит короткий preview и попросит время. Ответы `завтра в 9`,
  `через 2 часа` и явная дата поддерживаются в течение 15 минут.
- Контекстный reminder можно редактировать, отложить, выполнить или удалить обычными
  action-кнопками.

## Что сохраняется

Контекст извлекается отдельным заменяемым Telegram adapter/service. Для каждого reminder
сохраняется одна нормализованная запись с ограниченными текстом/подписью, ссылкой,
идентификаторами chat/message, безопасной публичной username-ссылкой и bounded media
metadata. Файл не скачивается. Если есть `file_id`, worker сначала пробует отправить
фото/документ через Telegram file reference; при недоступном file_id отправляется текстовый
fallback.

Произвольные URL не запрашиваются и не проверяются сетевым обращением. Неизвестные,
неполные или приватные ссылки остаются только текстом; raw context не попадает в логи и
административные метрики.

## Ownership, retention и fallback

Context row дополнительно сверяет `user_id` и `chat_id` с reminder при delivery. Поэтому
наличие одинакового `reminder_id` или callback не даёт другой переписке доступ к контексту.
Контекст хранится 30 дней. Worker периодически удаляет истёкшие rows по kind; reminder и
его основной текст сохраняются. Если row уже удалена, источник удалён или media недоступно,
доставка сообщает, что исходный контекст истёк/недоступен, и сохраняет actionable reminder.

Текстовый snapshot может быть доставлен до истечения TTL даже если исходное сообщение в
Telegram удалено. Это не является архивом Telegram и не включает channel reader,
publishing workflow, TMA или загрузку больших media.
